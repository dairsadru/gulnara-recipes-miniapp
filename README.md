# Вкусно с Гульнарой — мини-приложение Telegram

Статическая страница мини-приложения для бота @gulnara_recbot.
Выбор продуктов, кухни (включая кухни народов Дагестана) и калорийности отправляется боту:

- если приложение открыто кнопкой клавиатуры в чате — через `Telegram.WebApp.sendData`;
- если открыто кнопкой меню, инлайн-кнопкой или в браузере — через ссылку `t.me/gulnara_recbot?start=<код>`
  (код до 64 символов: действие, кухня, народ, калорийность и продукты). Бот расшифровывает его в `/start`.

Рецепт приходит в чат. Здесь только интерфейс: без ключей, токенов и данных пользователей.
